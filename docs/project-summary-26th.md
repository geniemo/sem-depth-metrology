# 프로젝트 정리 — SEM 영상 기반 깊이 계측 (26위 달성까지)

> 서류(이력서·자소서·포트폴리오) 작성용 소재 문서. 모든 수치는 실측 기록
> (`experiments/results.csv`, `experiments/submissions.csv`) 기준이며 검증 가능.

## 0. 한 줄 요약

시뮬레이션에만 픽셀 정답이 있는 sim-to-real 조건에서, 반도체 SEM Top-down 영상으로부터
픽셀별 깊이(Depth Map)를 복원하는 대회 과제(2022 Samsung AI Challenge: 3D Metrology,
Dacon 실서버 채점)를 단독 수행 — **순수 시뮬레이션 베이스라인 RMSE 8.000(118위)에서
가설-검증 사이클 6회로 4.597(제출 172팀 중 26위, 등록 790명)까지 개선**. 하루(1 GPU) 안에
구축·실험·문서화 완료.

- 대회: https://dacon.io/competitions/official/235954 (종료 대회, 실서버 연습 제출로 채점)
- 저장소: 로컬 git (테스트 32개, config 1개=실험 1개 관리, 모든 실험·제출 CSV 자동 기록)
- 환경: RTX 5070 Ti 1장, PyTorch(cu128)+timm, uv

## 1. 문제가 어려운 이유 (3중 어긋남)

| 데이터 | 규모 | 라벨 |
|---|---|---|
| 시뮬레이션 | 구조 21,663종 × 4촬영조건(Case) × 2노이즈(itr) = SEM 173,304장 | 픽셀별 Depth Map 86,652장 |
| 실제 train | 2,059 site × ~29장 = 60,664장 | site당 평균 깊이 스칼라 1개 |
| 실제 test | 25,988장 | 없음 (Depth Map PNG 제출, RMSE) |

1. **외형 갭**: sim은 거친 노이즈(픽셀 μ/σ 99.9/57.8), real은 부드러움(115.6/65.8)
2. **라벨 인코딩 불일치**: sim Depth 픽셀은 "작을수록 깊음", real `average_depth`는
   "클수록 깊음"(물리 스케일) — 둘을 잇는 사상이 미지수
3. **라벨 시프트**: sim depth 맵의 영상 평균은 111±7.5에 몰려 있는데 real은 105~142
   4군집 — sim은 real 깊이 범위의 가운데만 커버

## 2. 수행 내용 (단계별: 무엇을/왜/결과)

### Phase 1 — 재현 가능한 실험 인프라 (반나절)
- uv 기반 프로젝트, `semdepth` 패키지(데이터/모델/학습/추론/제출), TDD로 구축
  (**합성 픽스처**로 실데이터 없이도 전 파이프라인 테스트 — 총 32개 테스트, 경고 0)
- 실험 1개 = YAML config 1개, 결과는 `results.csv`에 자동 축적 → ablation 표가
  리포트 재료로 직결
- RTX 5070 Ti(Blackwell/sm_120) 호환을 위해 PyTorch cu128 인덱스 핀 고정

### Phase 2 — 데이터 검증에서 잡은 치명적 함정 (누수)
- 압축 해제 직후 검증 스크립트로 전수 대조: **동일 구조가 4개 Case에 완전 반복**
  (21,663개 파일명 100% 중복)을 발견 → 케이스 단위 스플릿이면 같은 구조가
  train/val 양쪽에 들어가 검증 점수가 부풀 상황
- **구조 이름(group_id) 단위 그룹 스플릿**으로 설계 변경, 누수 방지 테스트로 고정
- 부수 발견: 대회 페이지 수치의 오기(60,664 vs 실측 60,665 — 주최측이 실수로 포함한
  Jupyter 체크포인트 파일 1장), sim "259,956"은 SEM+Depth 합계라는 사실 규명

### Phase 3 — 물리 기반 EDA (도메인 갭의 정량화)
- site 평균 밝기 ↔ 평균 깊이 상관 **r = −0.977**: "깊은 홀일수록 이차전자가 못 빠져나와
  어둡다"는 SEM 물리가 데이터에 그대로 새겨져 있음을 확인
- 라벨 인코딩 불일치·라벨 시프트를 상관 부호 분석으로 판별 (위 3중 어긋남의 ②③)
- real train↔test 픽셀 분포가 사실상 동일(115.6/65.8 vs 115.6/65.9)함을 확인 →
  제출 없이 real train으로 계산하는 프록시 지표의 대표성 근거 확보

### Phase 4 — 베이스라인과 검증 체계
- timm 인코더 + 직접 구현한 U-Net 디코더(크기 무관 패딩), sim 지도학습
  → sim hold-out RMSE 2.085, **LB 8.000 (118위)**: 도메인 갭이 점수를 지배함을 실측
- 제출 없이 성능을 추정하는 2축 검증: sim hold-out(픽셀·sim) + **cal-proxy**
  (real 6만 장에서 `avg_depth ≈ α+β·mean(pred)` 최소제곱 잔차 — 인코딩 미지수 우회)
- 학습 속도 실측(1 epoch=43초) 기반으로 스케줄 설계 — 실험 반복이 15~30분 단위

### Phase 5 — 실패 3건이 가리킨 것: "밝기는 노이즈가 아니라 신호"
- E0 전역 입력 정렬, E1 밝기·대비 랜덤화: 표준 도메인 어댑테이션 직관대로 외형 갭을
  공략 → **둘 다 로컬 지표 악화로 기각**. 원인: 절대 밝기가 깊이 신호의 주 운반자
  (r=−0.977)인데 그걸 지워버림
- E3 self-training: **로컬 지표는 전부 개선되는데 LB만 악화(5.33→5.63)** —
  pseudo 라벨의 확증 편향 + "cal-proxy는 평균이 풀린 뒤 픽셀 오차를 못 본다"는
  지표의 사각지대를 실험으로 확정. 이후 제출을 가설 검증 단위로만 사용(총 6회)

### Phase 6 — 약지도 EM-아핀 (핵심 기여 ①): LB 8.00 → 5.33 (39위)
- 미지의 라벨 사상 (α,β)를 **매 epoch 폐형 최소제곱으로 재적합**하면서
  `L1_sim + λ·|α+β·mean(pred_real)−avg|`로 학습하는 EM 구조 설계
- sim L1이 픽셀 형상의 앵커, real 평균 제약이 예측 대역을 라벨 분포로 확장 —
  잘못된 인코딩 가정을 고정하지 않는 것이 핵심 (cal-proxy 5.37→1.84, corr 0.986)

### Phase 7 — 프레임 평균 가설 (핵심 기여 ②): 5.33 → 5.11 (35위)
- "real 영상이 부드러운 이유 = 다중 프레임 평균"이라는 물리 가설을 세우고,
  sim이 제공하는 **노이즈 실현 쌍(itr0/itr1)의 평균을 학습 입력**으로 사용 —
  밝기를 전혀 훼손하지 않고 real의 look에 접근
- 약지도 이전 시점의 전이력이 즉시 개선(cal 5.41→3.83)되어 가설을 로컬에서 검증한 뒤 제출
- 잔여 블러를 **방사형 파워 스펙트럼 매칭으로 σ=0.7로 계측**(감→측정) — 캘리브레이션된
  증강으로 후속 멤버 학습

### Phase 8 — 앙상블·TTA (마무리): 4.597 (26위) + 구성 실험
- 가설이 다른 3개 모델(itr-평균 r34 / +블러 r34 / convnext_tiny) 평균 + flip TTA
  → **-0.52 개선, 4.597/4.618 (Public/Private), 26위**
- 6멤버 확장 실험은 4.657로 후퇴 — **"앙상블은 질>양"** 을 데이터로 확인 (희석 효과)
- 참고: 본대회 최종 리더보드 기준 20위 컷이 4.796이므로, 이 점수는 그 기준으론 20위 안쪽

## 4. 규모·스택 (팩트 시트)

- 데이터: 이미지 총 34.6만 장(48×72 grayscale), 1.2GB
- 실험: 학습 런 12회+ (전부 시드 고정·config 기록), LB 제출 6회 (하루 10회 한도 내 선별)
- 코드: `semdepth` 패키지 7모듈 + 스크립트 9개, 테스트 32개(누수 방지 스플릿·TTA
  라운드트립·EM 재적합 폐형해 등 규약 고정), pytest 경고 0
- 스택: Python 3.12, PyTorch 2.11(cu128), timm, uv, TensorBoard
- 총 소요: 계획~26위까지 실질 1일 (GPU 학습 시간 지배, 단계당 15~30분 반복)

## 5. 서류에서 뽑아 쓸 핵심 의사결정 5가지

1. **누수를 사전에 잡은 스플릿 설계** — 데이터 전수 검증으로 구조 반복을 발견,
   그룹 스플릿으로 차단 (검증 점수의 신뢰성 확보가 모든 후속 판단의 전제)
2. **미지 인코딩을 추정이 아닌 구조로 해결** — EM-아핀 약지도: 폐형 재적합으로
   퇴화를 막으면서 약한 라벨(평균 1개)로 라벨 시프트를 교정
3. **표준 기법의 실패를 물리로 해석** — 밝기 랜덤화·전역 정렬·self-training 3연속
   실패가 "밝기=신호, 프록시의 사각지대"라는 하나의 결론으로 수렴함을 규명하고,
   이후 모든 선택(밝기 보존형 정합)의 근거로 사용
4. **가설→로컬 검증→제출의 규율** — 제출을 실험 단위로 아끼고(6회), 로컬 지표의
   유효 구간과 사각지대를 실험으로 그어가며 사용
5. **캘리브레이션의 계량화** — 블러 강도를 감이 아니라 파워 스펙트럼 매칭으로 측정(σ=0.7)
