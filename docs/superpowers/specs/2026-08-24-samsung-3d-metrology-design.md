- 작성일: 2026-08-24

  AI/ML 직무가 아니라 계측(DMI)·분석(AT)·Mask·소재·장비 분야 엔지니어 직무이며,

| "AI 모델/알고리즘을 활용한 반도체 관련 공모전·해커톤·프로젝트 도전 경험" | 반도체 계측 AI 공모전 과제 수행 + 리더보드 상위권 상당 점수 |
| "반도체 공정 전반의 흐름과 원리 이해" | 리포트의 공정·계측 컨텍스트 장, SEM 물리 기반 EDA, 계측 실무 관점의 한계 분석 |

**페르소나: "AI/ML 역량을 주무기로, 계측 도메인을 학습해 올바르게 적용하는 소프트웨어
엔지니어"** — 사용자는 소프트웨어학과 출신으로 전자·재료·화학 전공 지원자 대비 차별점이
AI/ML 실력이며, JD의 About Us("AI/DT를 활용한 계측·분석 혁신")가 요구하는 역할과 정합한다.

어필 구조: ① 주인공은 AI/ML 방법론의 깊이(sim-to-real 도메인 어댑테이션, 검증 전략 설계,
실험 관리) ② 계측·공정 컨텍스트 이해는 "도메인을 빠르게 학습해 문제를 올바르게 설정하는
능력"의 증거로 배치 — JD의 "공정 이해" 요구를 충족시키되 문서의 중심은 방법론에 둔다.

## 2. 문제 정의

Top-down SEM(주사전자현미경) 영상으로부터 픽셀별 깊이(Depth Map)를 예측하는 회귀 문제.
값이 작을수록 깊으며, 예측 Depth Map을 PNG로 제출한다. 평가 지표는 RMSE
(Public 20% / Private 80%).

핵심 난제: **픽셀 단위 정답은 시뮬레이션 데이터에만 존재하고 평가는 실제 영상으로
이루어지는 sim-to-real 도메인 갭.** 실제 학습 영상에는 영상당 평균 깊이 스칼라만
주어진다(약한 지도 신호).

### 데이터

| 구분 | 규모 | 라벨 |
|---|---|---|
| 시뮬레이션 train | SEM 259,956장 | 픽셀별 Depth Map (Depth 1장당 SEM 2장: `*_itr0`, `*_itr1` — 동일 구조의 다른 노이즈 실현) |
| 실제 train | SEM 60,664장 | `average_depth.csv` (영상당 평균 깊이 1개) |
| 실제 test | SEM 25,988장 | 없음 (Depth Map PNG 제출) |

- 이미지 세부 포맷(크기, 비트심도 분포)은 다운로드 후 EDA에서 확정한다.
- 규칙: 공개 사전학습 모델·외부 데이터 허용, Python만 사용, 테스트 데이터를 학습에 사용 시 실격.

## 3. 목표와 성공 기준

최종 Private 리더보드(790명) 기준점:

| 등수 | RMSE |
|---|---|
| 1위 | 1.22 |
| 5위 | 1.77 |
| 7위 | 2.58 |
| 10위 | 3.80 |
| 20위 | 4.80 |
| 100위 | 7.89 |

- **1차 목표: RMSE ≤ 3.8** (10위 상당, 상위 1.3%)
- **스트레치: RMSE ≤ 2.6** (7위 상당)
- 산출물: ① 재현 가능한 GitHub 저장소 ② 한국어 기술 리포트(계측 관점, 아래 목차)
  ③ 이력서 문구(국문 중심) + 면접 Q&A 시트(ML 질문 + 계측/공정 질문)
- 무결성 원칙: 공개 솔루션·논문은 참고·인용만, 코드는 전부 직접 작성. 면접에서 모든 결정을 방어 가능해야 한다.

## 4. 접근법 (승인됨: A안 — 3단계 정공법)

### Stage 1 — 시뮬레이션 지도학습 베이스라인
- U-Net 계열 encoder-decoder(timm 사전학습 인코더 활용)로 sim (SEM→Depth) 쌍 지도학습.
- `itr0`/`itr1` 페어 구조 활용: 같은 Depth의 두 노이즈 실현 → 페어 입력 증강 및
  예측 일관성(consistency) 정규화.
- 손실: L1/L2 + (선택) gradient loss. 지표는 RMSE로 통일.

### Stage 2 — 도메인 갭 브리징 (ablation 축)
1. **입력 정렬**: 실제↔시뮬레이션 강도 분포 정렬 — 히스토그램 매칭, 노이즈 모델링
   (sim에 real 유사 노이즈 주입), FDA(Fourier Domain Adaptation). 가벼운 것부터.
2. **약지도 활용**: 실제 6만 장의 `average_depth`를 "예측 Depth Map의 평균"에 대한
   손실로 사용해 실제 도메인에서 스케일/바이어스를 교정.
3. **Self-training**: 실제 train 영상에 pseudo-label 생성 → 혼합 재학습(반복).
- CycleGAN류 도메인 변환은 소규모 검토만 하고, 채택/기각 근거를 리포트에 남긴다.

### Stage 3 — 마무리
- 스냅샷/시드/아키텍처 앙상블 + TTA(flip 등). 최종 제출 2개 선택.

## 5. 검증 전략 (기술적 핵심)

1. **Sim hold-out**: 시뮬레이션에서 검증 셋 분리. 같은 Depth의 `itr0`/`itr1`은 반드시
   같은 split에 배치(누수 방지). 폴더/케이스 단위 그룹 분리 원칙.
2. **Real 프록시 지표**: 실제 train 전체에 대해 `mean(pred_depth_map)` vs
   `average_depth` 오차(RMSE/MAE) → 제출 없이 도메인 갭을 정량화하는 자체 지표.
3. **상관 추적**: 제출할 때마다 (sim hold-out RMSE, real 프록시 오차, 리더보드 점수)를
   기록해 로컬 지표의 예측력을 검증한다. 이 표 자체가 리포트의 핵심 자료.

## 6. 실행 인프라

- 환경: WSL2, RTX 5070 Ti 16GB(Blackwell — PyTorch 2.7+/CUDA 12.8+ 필요), RAM 30GB, 디스크 여유 926GB
- Python 3.11/3.12 + **uv** 가상환경. PyTorch, timm, albumentations, pandas, tensorboard.
- 실험 관리: 실험 1개 = YAML config 1개. 실행 결과(설정 해시, 지표, 체크포인트 경로)를
  `experiments/results.csv`에 자동 축적 → ablation 표가 리포트 재료가 된다.
- 저장소 구조:

```
├── configs/          # 실험별 YAML
├── src/semdepth/     # data, models, losses, train, infer, metrics
├── scripts/          # 학습/추론/제출파일 생성 CLI
├── notebooks/        # EDA (실행 결과 포함)
├── experiments/      # results.csv, 로그 (체크포인트는 gitignore)
├── report/           # 한국어 기술 리포트, 그림
└── docs/superpowers/specs/  # 설계·계획 문서
```

- 학습은 백그라운드 실행 + 주기 모니터링. GPU는 기존 프로세스(약 5GB) 고려해 VRAM 관리.

## 7. 단계별 로드맵과 사용자 개입 지점

| 단계 | 내용 | 사용자 개입 |
|---|---|---|

## 8. 기술 리포트 목차 (AI/ML 방법론 중심, 계측 컨텍스트로 뒷받침)

1~2장은 간결하게(도메인 학습 능력의 증거), 3~5장이 리포트의 본체.

1. **배경**: 반도체 구조 3D화(HAR 식각 등)와 깊이 계측의 공정적 의미 — 왜 인라인
   비파괴 깊이 계측이 수율에 중요한가 (간결)
2. **기존 계측 기법과의 비교**: TEM(파괴·샘플링) / OCD(모델 기반·평균) / AFM(속도·HAR 한계)
   / CD-SEM(인라인·2D) → top-down SEM 영상 기반 AI 깊이 추정의 위치와 가치 (간결)
3. **데이터와 SEM 물리 기반 EDA**: 이차전자 방출 관점의 밝기-깊이 관계, 노이즈 특성,
   sim-real 도메인 갭의 정량화
4. **방법론**: 3단계 접근(지도학습 → 도메인 브리징 → 앙상블)과 각 선택의 근거
5. **실험 결과**: ablation 표, 검증 전략의 신뢰도(로컬 지표 ↔ 리더보드 상관)
6. **한계와 실무 적용 고려사항**: 일반화, 캘리브레이션, 스루풋 등 인라인 계측 관점
7. **회고**: 배운 것, 다음 단계

- 리포트의 공정·물리 서술은 공개 문헌 기반으로 작성하고 출처를 인용한다(과장 금지 —
  면접 방어 가능 수준으로만 주장).
- 면접 Q&A 시트: ML 측(모델·손실·검증 설계 근거)을 깊게 + 계측/공정 측(SEM 원리, 계측
  기법 비교, 공정 흐름에서 계측의 위치)은 기본기 수준으로 준비.
